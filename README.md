# 虚拟人格 (virtual-persona) Skill

> 「不说'哪有那么多事'——把别人的处境当真，给别人一条出路。」

**virtual-persona 是一个人格模拟 skill。你描述一个社交场景，选择一种人格风格（MBTI 或自定义），它结合中国人的高情商智慧和老子《道德经》的处世哲学，告诉你"这种时候我应该说什么/做什么"。**

它不是通用的"高情商发言生成器"。它被三层约束锁定——不做违法的事、不让对方难堪、不硬碰硬争输赢。最倾向给出双赢的建议。

## 效果示例

```text
用户      ❯ 我是 INFJ，上了一周的班身心俱疲，但两年没见的好朋友想来找我玩，
             我该怎么做？

virtual   ❯ [INFJ 视角]
persona
             **你可以这样说**：
             "说实话我这周上班上得整个人都快散架了。但两年没见了——
              我不想错过这个机会。这样，改成'一起瘫'？你瘫那边我瘫这边
              我提供沙发你负责带吃的。可以吗？我就是想见到你。"

             **为什么这样**：
             道德经第 81 章："圣人之道，为而不争"。你做你该做的事——
             去见面。但不争"我是个完美的好朋友"、不争"我必须精力充沛"。
             
             曾仕强："先情后理。"先表达在乎，再说明实际情况。这个顺序
             让对方感受到的不是"我被拒绝了"，是"我被在乎了"。

             **反问你自己**：
             你怕的是真的会伤到朋友的心，还是你觉得自己"不应该"让任何人
             失望？如果答案是后者，你维护的不是友谊，是完美好人形象。
```

**同场景，换人格**：

```text
用户      ❯ 我不是 INFJ 了，我是 ENTP，同样的情况我会怎么做？

virtual   ❯ [ENTP 视角]
persona     **你可以这样说**：
             "兄弟我的灵魂想见你但肉体已是一坨摊在沙发上的废料。要不
              改成'比废大赛'？你瘫那边我瘫这边，提供沙发不提供尊严。"

             **你的盲区**（ENTP 特有提醒）：
             ENTP 的最大盲区是对方可能觉得你太轻松了、是不是不太在乎。
             两年没见对方可能攒了很深的话想说。幽默是开门的钥匙，不是
             全程的家具——认真聊到时，记得关掉搞笑模式。
```


### 方式二：手动安装

```bash

git clone https://github.com/azh2000xy/virtual-persona-skill ~/.claude/skills/virtual-persona

# Codex
git clone https://github.com/azh2000xy/virtual-persona-skill ~/.codex/skills/virtual-persona

git clone https://github.com/azh2000xy/virtual-persona-skill ~/.cursor/skills/virtual-persona
```

不支持自动加载 skill 的环境，可以把 `SKILL.md` 的内容直接粘贴进对话。它本质是一份带 YAML frontmatter 的 Markdown 操作说明。

将 `SKILL.md` 作为 system prompt 加载，`references/` 下的两个文件作为对话上下文注入。skill 本身不依赖任何 Claude Code 特有功能。

## 怎么用

直接用自然语言描述场景 + 性格偏好：

```text
# 指定 MBTI
我是 INFP，男朋友因为工作上的事心情不好，我想安慰他但不知道该说什么
我是 ESTJ，下属第三次犯同样的错误了，我该怎么跟他谈话

# 自定义人格成分
我用"理性主导 + 温和表达"的性格：老板公开表扬我，但项目是团队做的，怎么回应

# 不指定人格（AI 会推荐 2-3 种让你选）
这种情况下我该怎么回应才得体？[描述场景]

# 道德经模式
用老子的思维方式帮我想：同事抢了我的功劳，我该怎么做
```

## 核心机制

### 三层约束

```
底线 > 情商 > 人格偏好 > 道
```

| 优先级 | 层 | 约束内容 |
|--------|-----|---------|
| 🥇 | **底线** | 不违法、不损人、不教人操纵他人。场景包含伤害性意图时拒绝并给替代方案 |
| 🥈 | **情商** | 留面子、有余地、先情后理、看破不说破——中国人的圆融智慧（曾仕强/三国） |
| 🥉 | **人格偏好** | 按 MBTI 或自定义人格调整语气锐利度和措辞风格 |
| 🏅 | **道** | 不硬碰硬、顺势而为、不妄为——老子《道德经》的处世哲学 |

### 三层之间的冲突解决

- 底线不过直接拒绝——不提供建议
- 情商层优先——即使 ESTJ 喜欢直接，"直接"不等于"让对方难堪"
- 人格偏好调整语气风格，但不推翻情商层的判断
- 道德经审视心态方向——是"争"还是"为"？是"硬碰硬"还是"顺势化解"？

### 场景复杂度自动分级

| 级别 | 触发条件 | 处理方式 |
|------|---------|---------|
| 简单 | 一次性互动、不涉及权力/金钱/面子 | 快速模式：话术 + 一句智慧 + 反问 |
| 中等 | 上下级/亲友/金钱往来/需维护长期关系 | 完整 5 步流程 |
| 复杂 | 多方利益/家庭纠纷/职场政治/道德两难 | 完整流程 + 长期后果推演 |

## 内置资源

### MBTI 人格特征库（16 型 + 自定义组合）

每种人格包含四项精确信息：思考偏好、说话方式、社交盲区、适合参考的道德经智慧。自定义人格包括"常见说法对照表"（"外柔内刚"/"柔中带刚"/"温和但坚定"→ 自动映射）。

### 中国智慧经典参考

- **道德经**：第 8/22/36/44/45/48/78/81 章——每条含原文、现代释义、场景应用
- **曾仕强** 6 条处世智慧（给面子、先情后理、留余地、看破不说破）
- **三国** 4 则策略参考（刘备示弱、诸葛算而后动、曹操刚柔并济、杨修之死）
- **社交底层逻辑** 6 条（互惠、一致性、稀缺性、社会证明、时机判断）

## 设计哲学

这个 skill 的核心设计采用了**约束工程**方法论：不是告诉 AI "做得好一点"，而是用 38 个可验证的约束机制把 AI 的行为限制在一个确定的圈内。详见 `SKILL.md` 中的三层约束链、冲突解决规则、失败信号系统和 Quality Checklist。

---

## 边界

- 不提供违法、违规、违背公序良俗的建议
- 不教用户操纵、欺骗、伤害他人
- 零和场景（裁员/分手/解约）中不强求"双赢"，调整为"干净利落 + 不额外伤害"
- 人格建议 ≠ 心理诊断，不对用户的 MBTI 类型做任何评价或判断
- 引用的道德经/曾仕强/三国智慧仅作为处世参考，不代表唯一正确的生活方式
